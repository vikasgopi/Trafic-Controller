01 / COUNTER

Mod-N counter

A Mod-N counter cycles through N distinct values. For Mod-10, the count sequence is 0, 1, 2 … 9, then returns to 0.

Number of flip-flops = ⌈log₂ N⌉

For N = 10, four flip-flops are required because 2⁴ = 16.

02 / STATE MACHINE

Finite-state machine

The FSM stores the current traffic state and selects the next state whenever the counter produces a terminal-count event.

S0→S1→S2→S3↻

The sequence repeats continuously until reset.

03 / SAFETY RULE

Non-conflicting greens

The output decoder ensures that the main road and side road are never green at the same time.

MR Green≠SR Green✓

This is an educational logic model, not a certified traffic-control system.

CAPSTONE PROJECT

Designed to make
digital logic visible.

This project demonstrates sequential circuit concepts through a familiar real-world example. It brings together a clock, counter, finite-state machine and output decoder in one interactive learning model.

For academic demonstration only. Do not connect this prototype to real traffic infrastructure.
